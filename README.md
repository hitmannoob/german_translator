# Challenges faced
One of the biggest challenge faced was whenever the value is being selected/changed the entire app refreshes. Resolved that using fragments in streamlit but not sufficient for scale. Another major challenge faced was alignment of UI elements according to the layout. Streamlit doesnt have flexiblity regarding layout. Streamlit doesnt also store the user data and authentication in streamlit doesn't have also store the cache for a particular user. 

# What you'd need to go live
Tools which we would need to go live would be adding authenication so that only allowed users can log in. Also frontend based on Typescript or ReAct would be an ideal choice considering the scale.
